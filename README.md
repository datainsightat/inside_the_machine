# Inside the Machine

**Inside the Machine** is an interactive, beginner-friendly game that explains how language AI works—from tokens and context to probability, safety constraints, and external tools.

The experience uses visual metaphors to make AI easier to understand without suggesting that AI is conscious or experiences the world like a human.

## Features

- Beginner introduction to AI and language models
- Five interactive learning stages
- Explanations of capabilities, limitations, and common misconceptions
- Responsive, accessible interface with reduced-motion and sound controls
- Procedural visuals and audio
- Progress saving with `localStorage`
- No frameworks or external assets

## Run locally

Download the repository and open [`inside_the_machine.html`](./inside_the_machine.html) in a modern browser. No installation or web server is required.

## Project files

- `inside_the_machine.html` — the complete self-contained game
- `game-prompt.md` — the original reusable design prompt
- `README.md` — project overview

## Deploy on GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the branch containing `inside_the_machine.html` with the root folder. GitHub will provide a public URL for the game.
